DAY1

2月6日（正月初一）· 成都 → 北京 · 前门夜游

🚄 交通日前门小吃
  • 建议行程🚄

    成都东 → 北京西 高铁 二等座¥762–887

    最快 G322（06:56–14:26，约7.5h）或 G970（10:56–20:20）。3-4人家庭可早点出发，下午到京直接办入住。

  • 省钱备选🛏️

    动卧夕发朝至（省一晚房费）动卧约¥598

    D966/D968 成都东 19:28 → 次日 06:47 北京丰台，卧铺睡一觉即到，含一晚交通+住宿，适合抢不到白天票或想多留白天时间的家庭。

  • 15:30🏨

    入住酒店（前门/崇文门片区）

    放行李休息，地铁+步行可达各景点。

  • 17:30🥘

    晚餐：护国寺小吃 / 老北京小吃拼盘 ¥40–60

    豆汁焦圈、驴打滚、豌豆黄、艾窝窝、炒肝、糖葫芦，一次尝遍老北京风味。

  • 19:00🏮

    前门大街 · 大栅栏 · 鲜鱼口夜市 免费

    正阳门牌楼下看京味夜景，逛老字号（内联升、瑞蚨祥、张一元）。

  • 21:00🛌

    回酒店休息

    早睡，明早天安门+故宫行程较长。

🥛 当天吃什么

  • 晚：护国寺/前门老北京小吃 ¥50
  • 推荐：豆汁焦圈、驴打滚、艾窝窝、炒肝

🏨 住宿

前门 / 崇文门 / 灯市口地铁沿线，去天安门故宫步行或1-2站地铁。

💡 贴士

  • 春节部分胡同店关门，吃饭先查营业
  • 市内交通用“支付宝出行”北京地铁码

DAY2

2月7日（正月初二）· 中轴线经典一日

核心区约2万步需提前预约
  • 07:30🍜

    早餐：炒肝儿包子 / 糖油饼豆浆 ¥15–20

    推荐天兴居（前门鲜鱼口）、姚记炒肝（鼓楼）。

  • 08:30🏛️

    天安门广场（外观+升旗/拍照）免费 · 需预约

    参观人民英雄纪念碑、远望天安门城楼；带身份证，天安门广场需提前9天小程序预约。

  • 09:30🏯

    故宫博物院（约4h）淡季¥40/人

    午门入 → 太和殿 → 乾清宫 → 御花园 → 神武门出。珍宝馆/钟表馆各¥10（值得一看）。18岁以下免票须预约。

  • 13:30🍽️

    午餐：故宫周边/景山后街 ¥40–60

    故宫内餐饮偏贵，出神武门到景山后街找老北京面馆或护国寺小吃。

  • 14:30🌄

    景山公园（万春亭俯瞰故宫全景）¥2

    登万春亭中轴线制高点，俯瞰紫禁城红墙黄瓦全景，经典机位。

  • 16:00🛍️

    王府井步行街（可逛百货大楼）免费

    东来顺、护国寺分店都在附近；老北京风情街、王府井购书中心。

  • 18:00🍲

    晚餐：铜锅涮肉（东来顺/南门涮肉）¥80–120/人

    手切鲜羊肉、麻酱蘸料、糖蒜是灵魂。人均偏贵，是本次“东北亚美食放纵餐”。

🍲 当天吃什么

  • 早：炒肝包子 ¥18
  • 午：景山后街面馆 ¥50
  • 晚：铜锅涮肉 ¥100

🎫 预约重点

  • 故宫提前7天20:00放票，春节秒空必抢
  • 天安门广场提前约，安检严格
  • 随身带身份证，实名入园

💡 贴士

  • 故宫半日走中线精华，腿力不够可下次再看东西六宫
  • 景山万春亭拍全景别错过

DAY3

2月8日（正月初三）· 八达岭长城 + 奥运夜色

延庆·朝阳高铁游长城鸟巢外观免费
  • 07:00🍜

    早餐：豆腐脑+油条/馄饨 ¥12–18

  • 08:00🚄

    清河站乘京张高铁 → 八达岭长城站 ¥14–20/约20分钟

    节假日班次多，比大巴/自驾快且不堵，车票需提前买。

  • 08:40🧱

    八达岭长城（约3.5h）淡季¥35/人

    北线较陡、视野好；带老人小孩可选南线或乘缆车（往返¥140，可选）。春节山顶风大极冷，务必穿厚。

  • 12:30🍽️

    午餐：长城景区简餐或自带干粮 ¥40–60

    景区餐饮偏贵、选择少，建议背水和干粮，下山再好好吃。

  • 14:00🚄

    高铁返回清河站 → 市区

    约20分钟回城，下午可先回酒店补觉。

  • 16:30🛍️

    奥林匹克公园（鸟巢·水立方）外观免费

    傍晚到，看鸟巢水立方在暮色与灯光中变幻，拍照绝佳。

  • 18:30🍲

    晚餐：烤鸭（四季民福/便宜坊/全聚德）¥100–150/人

    北京烤鸭是家庭必尝，半只+荷叶饼卷鸭肉黄瓜条甜面酱。烤鸭店春节火爆需排号。

🍲 当天吃什么

  • 午：自带干粮 ¥30
  • 晚：北京烤鸭 ¥120

🎫 长城购票

  • 八达岭公众号/小程序提前预约门票
  • 清河→八达岭高铁票春节紧俏，先抢车票再买门票

💡 贴士

  • 长城风大，围巾口罩帽子全上
  • 登长城穿防滑鞋，部分台阶陡

    海碗居/方砖厂69号吃炸酱面；门框胡同百年卤煮、小肠陈吃卤煮。

春节穿衣指南（干冷 + 室内暖气）

北京冬季“室外干冷、室内暖足”，最好的策略是外厚内薄、便于穿脱。

🧥 外套（必备）

长款羽绒服 / 加厚棉服

  • 长款羽绒服防风保暖，首选
  • 冲锋衣外套（抗风）
  • 内搭毛衣/加绒卫衣

🧣 配件（保暖关键）

帽子·围巾·手套·耳罩

  • 毛线帽/耳罩（护头护耳）
  • 围巾、手套（户外逛长城必备）
  • 加绒裤 / 保暖打底裤

👟 鞋履 + 护肤

防滑保暖鞋 + 保湿

  • 防滑保暖运动鞋（路可能结冰）
  • 加厚棉袜
  • 润唇膏、护手霜、面霜（干燥）

🎒 行李清单（打勾用）

  • 身份证（购票/入园/酒店必备）
  • 学生证 / 老人证（门票半价或免票）
  • 羽绒服 + 加绒内搭
  • 毛线帽、围巾、手套、耳罩
  • 防滑保暖运动鞋 + 加厚袜
  • 润唇膏、护手霜、保湿面霜
  • 保温杯（天冷喝热水暖身）
  • 充电宝（≤100Wh，高铁飞机可带）
  • 常用药：感冒药、肠胃药、创可贴
  • 暖宝宝/暖贴（户外逛长城神器）
  • 干粮零食（长城、高铁上吃）
  • 少量现金（¥200应急）

故宫黄牛票/代抢

故宫仅官方小程序售票，未授权任何第三方；别买加价“黄牛票”，抢不到就候补或换行程。

✕

低价“长城一日游”

路边“几十元长城一日游”多为购物团（去水关长城/野长城）；认准官方八达岭+清河高铁直达。

✕

黑三轮胡同游乱收费

什刹海/南锣三轮车揽客含糊收费，先问清价格再坐；胡同步行免费自游更自在。

✕

景区旁“烤鸭”宰客店

烤鸭认准老字号（全聚德/便宜坊/四季民福/大董），景区周边“真空烤鸭”多为游客价。

✕

“玉器茶叶”购物点

一日游带去的玉器翡翠茶叶店水深，不冲动消费；伴手礼去稻香村、张一元、超市买。

✕

火车站门口黑车

北京西/南站出口黑车乱喊价，坚持地铁或官方出租车/网约车平台。

✕

春节闭店不自查

初一初二部分胡同小店、老字号闭店，用餐前地图App查“营业中”再出发。

✕

天气低估准备不足

北京干冷多风，长城风更大，羽绒服+围巾手套缺一不可；暖宝宝备足。
